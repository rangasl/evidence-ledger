Nirvāṇa as an exit condition

A formal model of liberation under the simulation hypothesis

Ranga, with Claude research agents25 November 20264 interactive figures

Each point is an agent. Brightness is craving; green is a noble stage. A point that reaches zero is not run again, and goes out.

Unfalsifiable

Given the simulation hypothesis and the Buddhist account of rebirth, nirvāṇa is coherently the one condition under which an agent stops being run. Nothing inside the simulation can show whether that is escape or deletion.

Abstract

We formalise the hypothesis that, if we live in a simulation, nirvāṇa is how an agent leaves it. The agent is a craving state carried from life to life, and the simulation runs it again while craving is above zero. Ordinary life raises craving at rate \(b\), practice lowers it at rate \(a\), and the noble stages never regress. Exit is certain whenever \(a > 0\). The expected number of lives grows exponentially with the number of craving levels once \(\rho = b/a\) exceeds 1, matching the canon's beginningless saṃsāra. The seven-lives teaching requires each post-stream-entry step to succeed with probability at least 0.76 per life. We prove that escape and deletion produce identical histories inside the simulation: the formal counterpart of the Buddha's refusal to say what happens to the liberated after death. Data on cessation events in meditation exist, but come mostly from one practitioner and describe reversible events, so they cannot test the hypothesis.

1 Introduction

This paper formalises one hypothesis and tests what follows from it. It does not claim the hypothesis is true.

Hypothesis N. Suppose (S) we are agents running inside a computed world, and (D) the Buddhist account of dependent origination describes the process that keeps an agent running. Then nirvāṇa, the complete ending of craving, is the condition under which the simulation stops re-instantiating that agent, and is its only exit.

Neither S nor D can be observed from inside, so N cannot be confirmed or refuted directly. What can be done is conditional: assume S and D, build the simplest model that honours both, and ask what nirvāṇa must then be, how likely it is, and what would count against it. The contributions are:

  1. a model in which craving sets whether an agent is instantiated again, with nirvāṇa as an absorbing state;
  2. conditions under which exit is certain or impossible, and the expected number of lives before it;
  3. an argument against the hypothesis's own framing. Leaving looks exactly like no longer being run, and the model cannot tell escape from deletion. Neither can the early texts, which refuse the question.

The method is the Evidence Ledger's: the strongest case, then the strongest attack, then what survives.

2 What leaving a simulation could mean

Bostrom's simulation argument concludes that at least one of three things is true: civilisations rarely reach the ability to run detailed simulations of minds, they rarely choose to, or we are almost certainly simulated [Bostrom 2003]. It says nothing about whether a simulated mind can leave.

From inside a computed world, an agent is not an object but a process: a state the system keeps updating and, if lives are separate runs, keeps re-creating. So "leaving" can only mean one of three things.

ReadingWhat happens to the agent's processWhat other agents observe
EscapeIts state continues outside the simulated worldThe agent stops appearing
DeletionIts state is no longer stored or runThe agent stops appearing
MergingIts state stops being kept as a separate agentThe agent stops appearing

All three look the same from inside; Section 6 makes that precise. Gaining control of the simulator from within is not leaving, and is outside the hypothesis. Hypothesis N needs a rule for when an agent is re-created. The simulation argument gives none, so N borrows one from Buddhism.

3 What the early texts say

The Pāli suttas supply N's mechanism, re-becoming fuelled by craving, and refuse to say what remains when it stops. Every text below was read in the translation linked. Where translators disagree, that is noted.

Craving drives becoming. Dependent origination runs in twelve links, ending craving (taṇhā) → clinging (upādāna) → becoming (bhava) → birth (jāti). The cessation is stated link by link: when craving ceases, clinging ceases, then becoming, then birth [SN 12.1; SN 12.2]. Sujato renders jāti as "rebirth" and Ṭhānissaro as "birth"; the model uses the less committed "birth".

Craving is fuel. Upādāna means both clinging and fuel. In MN 72 a fire burns dependent on grass and logs; when the fuel is used up it is reckoned "quenched" (nibbuto). In SN 44.9, a being between one body and the next is sustained by craving, as a wind-blown flame is sustained by the wind. This is the closest canonical text to the model's re-instantiation rule [MN 72; SN 44.9].

Where the fire goes is a malformed question. Asked which direction an extinguished fire went, the Buddha says the question does not apply, and gives the same answer to all four options about the Tathāgata after death: reappears, does not, both, neither. SN 22.85 rejects the view that an arahant is annihilated at death, and SN 12.15 rejects both "everything exists" and "nothing exists" [SN 22.85; SN 12.15].

Something unconditioned, or just an ending? Ud 8.3 says there is an unborn, unmade, unconditioned, without which no escape from the conditioned would be known: that reads like a place outside. SN 43.1 instead defines the unconditioned as the ending of greed, hate and delusion: that reads like an event. Iti 44 distinguishes nibbāna with residue (a living arahant) from nibbāna without residue at death, after which all becoming ceases [Ud 8.3; SN 43.1; Iti 44].

The round has no findable start. SN 15.3 says transmigration comes from an inconceivable beginning; the text says the beginning cannot be found, not that there is none. The wheel image (bhavacakra) is later and is not used here.

Etymology is contested. Most philologists derive nibbāna from "blowing out". Ṭhānissaro argues for "unbinding" and holds that early Indians thought of a quenched fire as latent rather than destroyed [Mind Like Fire Unbound]. That is his minority reading, argued from Vedic sources rather than the suttas.

4 The model

The agent is a state carried from life to life, not a self. That matches the no-self (anattā) view: what continues is a process, not an owner.

State. A craving level \(k \in \{0, 1, \dots, 3+L\}\). \(k = 0\) is nirvāṇa. \(k = 1, 2, 3\) are the three noble stages short of it (non-returner, once-returner, stream-enterer). \(k = 4, \dots, 3+L\) are \(L\) levels of ordinary craving.

Re-instantiation rule. At the end of each life the simulation runs the agent again if and only if \(k > 0\). This is assumption D in its sharpest form: craving is the fuel, and without fuel there is no further becoming.

Dynamics, one step per life. At ordinary levels craving falls one level with probability \(a\), rises one level with probability \(b\), and otherwise stays; the top level reflects. At the noble stages it falls one level with probability \(a_2\) and never rises, which encodes the Theravāda teaching that stream-entry cannot be lost. The ratio \(\rho = b/a\) compares how fast ordinary life rebuilds craving with how fast practice removes it.

The model makes four simplifications. Craving is one number, where the texts list many kinds and ten fetters. Each life is one step. The rates \(a\), \(b\), \(a_2\) are fixed, where the texts make them depend on meeting a teacher, effort and circumstance. And the rule makes re-instantiation certain while \(k > 0\): a simulator that dropped agents at random would allow exit without nirvāṇa, which D rules out.

5 Results

Exit is certain whenever practice can lower craving at all, but the expected wait explodes once ordinary life rebuilds craving faster than practice removes it.

Proposition 1 (exit is possible exactly when practice works). If \(a > 0\) and \(a_2 > 0\), the agent reaches nirvāṇa with probability 1 from any starting level. If \(a = 0\), it never leaves the ordinary levels.

Proof. The chain is finite, and state 0 is absorbing and reachable from every state when \(a, a_2 > 0\), so absorption is certain. When \(a = 0\), no transition goes below level 4.

Proposition 2 (how long it takes). From the top ordinary level, the expected number of lives before exit is

$$E = \frac{1}{a}\sum_{j=1}^{L}\sum_{m=0}^{L-j}\rho^{m} + \frac{3}{a_2}$$

where the double sum has the closed form

$$\sum_{j=1}^{L}\sum_{m=0}^{L-j}\rho^{m} = \begin{cases} \dfrac{L(L+1)}{2}, & \rho = 1 \\[6pt] \dfrac{1}{\rho-1}\left(\dfrac{\rho\,(\rho^{L}-1)}{\rho-1} - L\right), & \rho \neq 1 \end{cases}$$

Proof sketch. Let \(T_j\) be the expected lives to fall from ordinary level \(j\) to \(j-1\). First-step analysis gives \(T_L = 1/a\) and \(T_j = 1/a + \rho\,T_{j+1}\). Summing the \(T_j\) gives the double sum; the noble stages add three geometric waits of mean \(1/a_2\).

For \(\rho > 1\) the wait grows like \(\rho^L\): each extra level of craving multiplies it. A 20,000-run Monte Carlo matched the formula within 1.3% for four parameter sets (for example, 85.6 lives predicted against 84.6 simulated). Figure 1 reruns that check live in your browser.

Proposition 3 (the seven-lives bound). The texts say a stream-enterer is reborn at most seven more times. In the model the three remaining steps each succeed with probability \(a_2\) per life, so exit within seven lives is a binomial event:

$$P(\text{exit within } 7 \text{ lives}) = \sum_{k=3}^{7}\binom{7}{k}a_2^{\,k}(1-a_2)^{7-k}$$

Making it 99% likely needs \(a_2 \ge 0.76\). At \(a_2 = 0.5\) it is only 77%.

6 Escape or deletion?

The model cannot tell escaping the simulation from being deleted by it, and no observation made inside the simulation can either.

Proposition 4 (indistinguishability). Take any two simulators that share the rule "run the agent again while \(k > 0\)". In one, an agent reaching \(k = 0\) is copied out to the outer level; in the other, it is freed. Then every agent still inside has an identical history in both.

Proof. State 0 is absorbing: no transition leaves it, so nothing that happens to an exited agent enters the transition probabilities of the states that remain. With the same initial states and the same random draws, the inside histories coincide life by life.

This is the attack Hypothesis N has to survive, and as worded it does not. "Nirvāṇa is the exit" says more than the model supports. The supported claim is narrower: nirvāṇa is the condition under which the simulation stops running the agent. Three points soften this without rescuing the stronger claim.

  1. The texts make the same move. MN 72 and SN 22.85 refuse both "the liberated one persists elsewhere" (escape) and "is annihilated" (deletion). Proposition 4 is the formal version of that refusal: the question is unanswerable from inside, not merely unanswered.
  2. Deletion is the wrong word for what is lost. On the no-self view there was never a stored self, only a process fed by craving. If the process ends because its fuel ran out, nothing that was "you" is erased; what stops is the becoming. Deletion, like escape, assumes a self that is then disposed of.
  3. Ud 8.3 points the other way. It speaks of an unconditioned beyond the conditioned, which reads more like escape. SN 43.1 defines the same term as an ending. The canon does not settle it, and the model inherits the split.

One further cost. If the simulators wanted agents kept running, re-instantiation would not depend on the agent's own craving. N therefore implies the simulators built in a way out, which is a claim about their aims with no evidence behind it.

7 What could test it

The exit itself cannot be tested. Two fragments touch data: whether craving can reach zero, and whether its ending is a discrete event rather than a fade.

Fragment of NTestCurrent evidence
Craving can fall to zero, not just lowerLong-term follow-up of practitioners reporting full awakening, with behavioural measures of craving and reward-seekingNone systematic
Ending craving is a discrete eventBrain recordings during reported cessation eventsOne practitioner, 37 events; one 7T fMRI study, 3 people
Cessation differs from sleep or a seizureProbe responses during the event, compared with sleep and absence seizuresNot yet done
Re-instantiation depends on cravingWould first need evidence of rebirth at allNone accepted by science

What the cessation studies found. One long-term practitioner produced 37 graded cessation events across 29 EEG sessions [Chowdhury et al. 2023]. Alpha power fell over the 40 seconds before each event, and whole-brain alpha connectivity fell from about 21 seconds before [van Lutterveld et al. 2024]. A 7-tesla fMRI study of three people found selective, not global, changes during extended cessation [Yang et al. 2026].

Why it settles little. The EEG papers re-analyse the same single participant, who is also a co-author. Event onsets are marked from blink artefacts and self-grading. No paper yet tests the events against sleep or absence seizures with an outside probe. And a cessation is brief and reversible: the person comes back. In canonical terms it is closer to nirodha-samāpatti, the temporary suspension of MN 43 and MN 44, than to the final nibbāna the model needs.

8 Prior art and novelty

The idea is not new. Only the formal model appears to be, and it is a standard tool applied to a new case.

WorkWhat it already saysWhat this paper adds

Vaibhāṣika vs Sautrāntika debateIs nirvāṇa a real existent, or a name for cessation? The escape-or-deletion question, centuries oldProposition 4: why it cannot be settled from inside

We found no peer-reviewed paper pairing the simulation hypothesis with nirvāṇa as an exit, and no stochastic model of rebirth with craving as the parameter. Two sources could not be read and may overlap: Steinhart on the theological implications of the simulation argument, and a 2023 comparison of Chalmers with Abhidharma attributed to Vaidya. The absorbing chain itself is textbook; what goes beyond it are the closed form (Proposition 2) and the constraint the seven-lives teaching places on post-stream-entry practice (Proposition 3).

9 Limitations and verdict

Verdict: UNFALSIFIABLE as stated. A weaker form is internally consistent: given S and D, nirvāṇa is the only condition under which the agent stops being run. That weaker form follows almost by definition once D is assumed, which is its main weakness. The model shows the hypothesis is coherent and puts numbers on it; it gives no reason to believe S or D.

  1. D is assumed, not shown. No accepted evidence supports rebirth, so the re-instantiation rule has nothing to be fitted to.
  2. Escape and deletion cannot be told apart (Proposition 4). "Exit" claims more than the model can deliver.
  3. The parameters are invented. The results are statements about shape, such as exponential growth in \(L\) when \(\rho > 1\), not predictions.
  4. Craving is one number. The texts describe ten fetters lost in a set order; a many-dimensional model might behave differently.
  5. The simulators' aims are unknown. N quietly assumes they built in a way out.

What would change the verdict

  • Toward WOUNDED or better: independent evidence that re-instantiation depends on an agent's state, which would be evidence for D. Nothing in physics or neuroscience currently provides it.
  • Toward DEAD: evidence that an agent's state ends at death regardless of craving, which would make the re-instantiation rule false.
  • No result about cessation events in meditation can move it on its own, because those events are temporary and the person returns.
