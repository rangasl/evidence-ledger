# Evidence Ledger

**Are we in a simulation? Is there free will?**
One claim a day. Each one gets its strongest case, its strongest attack, and a verdict.
We publish what dies as well as what survives. Nothing is edited after the fact; revisions are dated.

## Method
Advocate and Prosecutor research each claim blind to each other. A Judge verifies every
citation and rules. Verdicts: **SURVIVES**, **WOUNDED** (holds in a weaker form), **DEAD**,
**UNFALSIFIABLE** (philosophy, not evidence). See `CLAUDE.md` and `TEMPLATE.md`.
